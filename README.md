# Orbiter 2024 Non-Numpad Keymap

A lightweight, plug-and-play key binding configuration script for **Open Orbiter 2024**, designed for laptop users and compact keyboards without a dedicated physical Numpad.

---

## 🚀 Overview

Navigating panels and controlling spacecraft in Orbiter 2024 usually relies heavily on Numpad inputs. This project provides a custom configuration to remap essential Numpad controls onto standard main-keyboard keys so you can pilot without manually editing configuration files or using external key remappers.

---

## 🛠️ Installation & Usage

1. **Back up your original configuration:**
   Before applying any changes, make a copy of your existing `Keymap.cfg` file located inside your Orbiter root directory (typically under `Orbiter/Config/`).

2. **Apply the remapped keys:**
   * Copy the contents of this script/config into your `Keymap.cfg` file (or run the script to automatically overwrite/merge the bindings).

3. **Launch Orbiter 2024** and enjoy piloting without needing an external Numpad!
